# byte.learn

byte.learn is a series of standalone interactive tools built to make core computer science concepts click through hands-on exploration rather than static explanation. Inspired by explorable-explanation projects, each entry takes one fundamental idea — how binary works, how sorting algorithms compare, how pathfinding searches a grid — and turns it into a small, visually distinct playground you can manipulate directly. The goal isn't to replace writing code or reading docs, but to build the intuition that makes those things easier to learn in the first place.
