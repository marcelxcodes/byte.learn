How it works: each bulb is one bit. Press a button — it shows 1 and the bulb lights up, showing 0 keeps it dark. Every bulb stands for a power of two: 128 64 32 16 8 4 2 1, left to right. Add up the values of the lit bulbs and you get the decimal number on screen. Type a number into SET VALUE to watch the console work it out in reverse.
